# lotto

## 기능 목록
### 전체 기능 정리
- 로또 숫자
     - 1~45 중복되지 않는 숫자 6개
- 당첨 기준
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원
- 로또 구매
    - 로또 1장 1000원
    - 중복되지 않는 당첨 번호 + 보너스 번호 입력
- 당첨 비교
    - 당첨 내역 출력 
    - 수익률 출력
- 에러 처리
    - 잘못된 값 입력시 IllegalArgumentException 발생

### 레이어 구분
#### 입력
- [x] `구매 금액을 입력해 주세요.`
  - [x] 정수형 숫자. 자릿수 구분 x
  - [x] 1000원 단위로 입력
- [x] `당첨 번호를 입력해 주세요.`
  - [x] 정수형 숫자. `,` 로 입력 구분
  - [x] 1~45 까지 중복 없는 숫자
  - [x] 6자리 입력
- [x] `보너스 번호를 입력해 주세요.`
  - [x] 정수형 숫자. 하나만 입력

#### 처리
- [x] 로또 번호 발행
  - [x] 구매 금액 / 1000 만큼 로또 번호 발행
  - [x] 중복되지 않는 숫자 6자리
  - [x] 오름차순 정렬

- [x] 당첨 기준
  - 1등: 6개 번호 일치 / 2,000,000,000원
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - 3등: 5개 번호 일치 / 1,500,000원
  - 4등: 4개 번호 일치 / 50,000원
  - 5등: 3개 번호 일치 / 5,000원

#### 출력
- [x] 발행한 로또 수량 및 번호 출력
  - [x] 오름차순 정렬
  - [x] `${구매 금액 / 1000}개를 구매했습니다.`
  - [x] `[8, 21, 23, 41, 42, 43]`

- [x] 당첨 내역
  - [x] 구매한 로또 번호에서 일치하는 만큼 개수 출력
  - [x] 2등의 경우 3등과 헷갈리지 않게 처리 5+보너스
  - `당첨 통계`
  - `---`
  - `3개 일치 (5,000원) - 1개`
  - `4개 일치 (50,000원) - 0개`
  - `5개 일치 (1,500,000원) - 0개`
  - `5개 일치, 보너스 볼 일치 (30,000,000원) - 0개`
  - `6개 일치 (2,000,000,000원) - 0개`

- [x] 수익률
  - 소수점 둘째 자리서 반올림
  - `총 수익률은 62.5%입니다.`

- [x] 에러 문구
  - `[ERROR] ${에러 문구}`
